# Number Guessing Game CLI

A beginner-friendly Python command-line game where the computer generates a random number and the player tries to guess it.

## Features
- Generates a random number between 1 and 10.
- Allows repeated guesses until the correct number is found.
- Gives hints when guesses are too high or too low.
- Counts the player's attempts.
- Displays a congratulatory message when the player wins.

## Technologies Used
- Python 3
- Random module
- While loops
- Conditional statements

## How to Run

```bash
python3 number_guessing_game.py
```
